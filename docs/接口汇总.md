# 接口汇总

> 后端服务：`YT.EMSWebViewApiServer` v1.0
> 服务地址：`http://8.140.182.55:26029`
> Swagger：`http://8.140.182.55:26029/index.html`（规范文件 `/swagger/v1/swagger.json`）
> 文档校验日期：2026-10-29（全部接口均已实测）

## 通用约定

| 项 | 说明 |
|---|---|
| 请求方法 | **全部为 POST**（实测 GET 一律返回 `405`） |
| Content-Type | `application/json`（亦接受 `text/json`、`application/*+json`） |
| 请求体 | 各接口均可传空对象 `{}`；无 body 亦可（实测正常返回） |
| 鉴权 | 业务接口**无需登录态/token**，可直接调用（登录接口除外，走签名校验） |
| 响应信封 | `{ code, message, result }` |
| 例外 | `WorkSpace/workSpaceNameList` **不返回信封**，直接返回字符串数组 |

### 响应码

| code | 含义 | 出现场景 |
|---|---|---|
| 200 | 成功 | 各接口正常返回 |
| 255 | 登录失败，指令令牌错误 | `User/login` 签名校验不通过 |
| 256 | 用户已存在 | `User/insert` 重复 userCode |
| 500 | 用户名、密码错误，或者该用户已经失效 | `User/login` 签名通过但账号密码错误 |

> 说明：255（签名错误）与 500（账号密码错误）的对照关系已在同类服务（`https://r.xhedc.com/api/v2/User/login`）上验证成立。

## 6. Event / 事件分页

## 8. User / 登录

`POST /api/v1/User/login`

**请求参数**：`BLoginModel`

| 参数 | 类型 | 说明 |
|---|---|---|
| `userCode` | string | 登录名 |
| `userPwd` | string | 密码（明文） |
| `loginOn` | int64 | **秒级**时间戳 |
| `sign` | string | 签名，见下方算法 |

**签名算法**（已在同类服务验证成立）：

```
sign = md5(`userCode=${userCode}&&userPwd=${userPwd}&&loginOn=${loginOn}&&key=${KEY}`)
```

## 接入注意事项（前端）

1. **字符串数字**：`Device` 的 `Vol/Cur/WorkKW` 等为字符串，需转换；空串要处理。
2. **`eventList` 可能为 `null`**：分页无结果时为 `null` 而非 `[]`。
3. **`userInfo` 可能为 `null`**：`User/single` 查不到时返回 200 + null。
4. **曲线无时间戳**：`Meter` 各 `List` 需配合 `Device.TimeList`（720 点）。
5. **时间基准**：数据时间戳可能滞后于当前时间（现场观测约 50 分钟），
   前端已按**数据最新时间戳**对齐曲线，避免落在可视窗口外。
6. **无删除用户接口**：新增后无法物理删除，只能置 `enabled=0`。
7. **`workSpaceName` 语义不一致**：`Event/pageList` 返回序号 `"0"`，
   `Param` 与 `Device` 返回完整名 `WorkSpace0`。
8. **写接口无强校验**：`User/insert` 传空对象也会成功，前端需自行校验。
